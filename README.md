# Web Development Learning Evidence

---

## 1. Thông tin repository

**Tên repository:** `web-development-learning`

**Mục đích:**

- Lưu minh chứng hoàn thành nội dung học HTML, CSS, JavaScript, jQuery, SQL.
- Lưu ảnh kết quả làm quiz và exercise.
- Lưu ảnh thực hành debug bằng Chrome DevTools.
- Lưu ảnh minh chứng học ASP.NET MVC, Razor và LINQ.
- Quản lý toàn bộ minh chứng học tập trên GitHub.
